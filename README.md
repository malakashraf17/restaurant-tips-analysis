# Restaurant Tips Analysis

## Project Overview

This project analyzes the classic restaurant tips dataset to explore customer behavior, restaurant bills, tipping patterns, and factors that influence tip amounts.

## Dataset

- 244 records
- 7 attributes
- Restaurant bills and tips
- Customer gender
- Smoking status
- Day
- Time
- Party size

## Analysis

The project includes:

- Exploratory Data Analysis (EDA)
- Analysis of tips and total bills
- Customer behavior analysis
- Analysis by gender, day, and meal time
- Daily sales and tips analysis

## Machine Learning

A Linear Regression model was used to predict tip amounts based on:

- Total bill
- Gender
- Smoker status
- Day
- Time
- Party size

## Model Results

- R² Score: 44.4%
- Mean Absolute Error: $0.67

## Key Insights

- Saturday had the highest total bill and total tips.
- Dinner was the most common meal.
- Bill amount was the strongest predictor of tip size.
- The Linear Regression model explained approximately 44% of the variation in tips.
